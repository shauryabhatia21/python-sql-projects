# 🖥️ Tkinter Desktop GUI Applications

Interactive graphical desktop utility applications built with Python's native `tkinter` library.

---

## 📂 Applications Index

1. **`calculator_gui.py`**:
   - Modern desktop calculator with numeric grid keypad (`0-9`), standard operators (`+`, `-`, `*`, `/`), decimal, equals (`=`), clear, and exit buttons.
   - Robust evaluation with error prevention.

2. **`percentage_calculator_gui.py`**:
   - 5-subject student marks entry form.
   - Calculates total cumulative sum and exact percentage score.

3. **`sum_calculator_gui.py`**:
   - Rapid two-number adder with instant result rendering.

---

## 🚀 How to Run

```powershell
python calculator_gui.py
python percentage_calculator_gui.py
python sum_calculator_gui.py
```
