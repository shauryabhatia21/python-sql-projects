# 🧩 Python Fundamentals, Strings & Exception Handling

Core computer science logic implementations including string manipulation, custom exception handling routines, and multi-dimensional nested loops.

---

## 📂 Projects Index

1. **`string_algorithms.py`**:
   - Palindrome detection using both algorithmic iteration and fast slice indexing (`[::-1]`).
   - Case inversion and character analysis (counting alphabets, digits, vowels, and consonants).

2. **`exception_handling.py`**:
   - Graceful runtime protection using `try`, `except`, `finally`.
   - Handling `ZeroDivisionError`, `IndexError`, and user-defined `raise` exceptions.

3. **`nested_loops.py`**:
   - Two-dimensional nested loop applications.
   - Student matrix table iteration and 2D matrix additions.

---

## 🚀 How to Run

```powershell
python string_algorithms.py
python exception_handling.py
python nested_loops.py
```
