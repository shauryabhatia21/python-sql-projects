# Python & SQL Project Suite

An enterprise-ready portfolio suite of database-driven applications, data science utilities, and desktop GUI systems.

## 💼 Core Systems
- **Bank Management System**: Full transactional banking platform integrated with SQL / persistence storage.
- **Library Management System**: Book tracking, member management, and borrowing/return workflows.
- **Student Information System**: Dynamic CRUD management with SQL connectivity.
- **Pandas & NumPy Data Science**: Tabular analysis, statistical operations, and data exploration.
- **Tkinter GUI Suite**: Responsive desktop utilities including calculators and interactive dashboards.

## 🚀 Getting Started
```bash
python main.py
```
