# 🚀 Python & SQL Full Project Portfolio

A comprehensive, production-ready collection of Python applications, AI games, Tkinter desktop GUIs, data structures, SQL systems, file handling tools, and algorithms built by **Shaurya Bhatia**.

## 🌟 Projects & Modules Overview

| Module / Project | Technologies | Description |
|---|---|---|
| **[Akinator AI Game](./AKINATOR_AI_GAME)** | Python, Tkinter, JSON | Self-learning 20-questions character guessing game with Bayesian decision engine, animated canvas GUI, and terminal CLI. |
| **[Tkinter GUI Apps](./TKINTER_GUI_APPS)** | Python, Tkinter | Interactive desktop applications: full-featured numeric calculator, 5-subject percentage calculator, and two-number adder. |
| **[PANDAS Library System](./PANDAS)** | Python, Pandas, CSV | Lightweight file-based library system with persistent CSV tables for books, members, and issue transactions. |
| **[Library Management (MySQL)](./LIBRARY_MANAGEMENT_MYSQL)** | Python, MySQL, smtplib | Enterprise library tracker with dynamic issue IDs, member books limit enforcement, and automated email receipts. |
| **[Student Management](./STUDENT_MANAGEMENT_SQL)** | Python, Tkinter, MySQL | Dual-interface (Tkinter GUI form + interactive CLI CRUD) managing student enrollments and fee payments. |
| **[Bank Management (SQL)](./BANK_MANAGEMENT_SQL)** | Python, MySQL | SQL-backed customer account creation, deposits, withdrawals, and account statements. |
| **[OOP Systems](./OOPS_PROJECTS)** | Python (OOP) | Classes, encapsulation, and multi-level inheritance: SBI Banking, Scientific Calculator, and Student Result Sheet. |
| **[Data Structures](./DATA_STRUCTURES_PROJECTS)** | Python Dictionaries, Lists | Fast in-memory hash map systems: Kotak Mahindra banking with funds transfer, Student records, and Contact book. |
| **[File Handling](./FILE_HANDLING_PROJECTS)** | Python `pickle`, `csv`, I/O | Persistent binary serialization (`customer.dat`), CSV student records (`student_records.csv`), and text analyzers. |
| **[NumPy & Data Science](./NUMPY_DATA_SCIENCE)** | NumPy, Matplotlib | Multidimensional array operations, matrix dot products, slicing, and 12 graph types (Line, Bar, Pie, Scatter, Histogram, Subplots). |
| **[Algorithms & Exceptions](./PYTHON_BASICS_ALGORITHMS)** | Python Core | Palindrome detection (slice & loop), character classifier, custom error handling (`try/except/finally`), and nested loops. |
| **[Basic Problem Solving](./BASIC_PYTHON_CODES)** | Python Basics | 24 standalone scripts covering powers, HCF/GCD, primes, factorials, Armstrong numbers, and star/number pyramids. |
| **[SQL Reference Guide](./SQL_NOTES_AND_COMMANDS)** | SQL (MySQL) | Complete query syntax, table schemas, join operations, constraints, and administrative commands. |


```powershell
python main.py
# or
python calculator_gui.py
```
