# Python & SQL Showcase Projects

A curated collection of Python and MySQL applications, data handling tools, and reference guides.

## Repository Structure

```text
github/
├── LIBRARY_MANAGEMENT_MYSQL/    # Full-featured Library System (Python + MySQL + Automated Emails)
├── LIBRARY_MANAGEMENT_CSV/      # File-based Library Management System (Python & Pandas)
├── STUDENT_MANAGEMENT_SQL/      # Student Admission System (Tkinter GUI + MySQL Console)
├── BANK_MANAGEMENT_SQL/         # Customer Banking Portal (MySQL CLI)
└── SQL_NOTES_AND_COMMANDS/      # Core SQL Reference Guide (DDL, DML, TCL)
```

## Projects Overview

| Project | Technologies | Description |
|---|---|---|
| **[Library Management (MySQL)](./LIBRARY_MANAGEMENT_MYSQL)** | Python, MySQL, smtplib | Full books, members, and issue/return tracking with automated email confirmations. |
| **[Library Management (CSV)](./LIBRARY_MANAGEMENT_CSV)** | Python, Pandas, CSV | Lightweight file-based library system with persistent CSV storage. |
| **[Student Management System](./STUDENT_MANAGEMENT_SQL)** | Python, Tkinter, MySQL | Dual-interface (Tkinter GUI and CLI CRUD) for managing student admissions. |
| **[Bank Management System](./BANK_MANAGEMENT_SQL)** | Python, MySQL | Customer accounts, transaction records, and account type management. |
| **[SQL Reference Guide](./SQL_NOTES_AND_COMMANDS)** | SQL | Complete syntax and commands guide for DDL, DML, and TCL. |

## Requirements & Setup
- Python 3.10+
- MySQL Server (`mysql-connector-python`)
- Pandas (`pip install pandas`)
