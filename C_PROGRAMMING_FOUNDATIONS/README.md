## 📂 Repository Structure

```text
c-programming-foundations/
├── BASIC CODE/
│   ├── check_div_by_2.c          # Modulo arithmetic parity test
│   ├── check_upper_lower_case.c  # ASCII character range classifier
│   ├── hello_world.c             # Standard I/O output stream
│   ├── marks_grade.c             # Multi-tier grading system (A/B/C/D)
│   ├── multiply.c                # Integer multiplication
│   ├── pass_fail.c               # Single-condition decision branching
│   ├── Square_area.c             # Geometric formula calculation
│   ├── sum.c                     # Two-integer addition
│   ├── switch_case.c             # Numeric jump-table switch construct
│   ├── switch_case_char.c        # Character-based switch-case branching
│   └── terminator_operators.c    # Inline ternary operator expressions
│
└── LOOPS/
    ├── FOR LOOPS/
    │   ├── 0_input.c             # Dynamic input-driven iteration
    │   ├── 1_100.c               # Linear sequential counter (1 to 100)
    │   ├── 100-1.c               # Decremental sequence iteration (100 down to 1)
    │   ├── BASIC_FOR_LOOP.c      # Standard for-loop syntax demonstration
    │   ├── check_digit_or_character.c # Comprehensive character/digit/symbol validator
    │   ├── float_loop.c          # Floating-point increment loop
    │   └── Heart.c               # ASCII shape rendering
    │
    └── WHILE LOOPS/
        ├── 0_input.c             # Sentinel condition termination loop
        ├── do_while.c            # Post-test exit condition loop
        ├── sum_while.c           # Iterative sum accumulator
        └── table.c               # Dynamic mathematical multiplication table
```

## 🛠️ Concepts & Engineering Highlights

- **Standard Streams & Formatting:** Safe formatting with `printf()` and `scanf()`.
- **Branching & Control Flow:** Multi-condition `if...else if...else`, jump-table `switch...case`, and ternary evaluation (`?:`).
- **Iteration Constructs:** Linear counting, decremental steps, accumulator patterns, sentinel breaks, and `do...while` execution guarantees.
- **ASCII Character Processing:** Validation of uppercase `[A-Z]`, lowercase `[a-z]`, digits `[0-9]`, and special characters using numeric range checks.
