# 📈 NumPy & Data Visualization (Matplotlib)

Data manipulation, vectorized linear algebra operations, and 2D charting routines.

---

## 📂 Projects Index

1. **`numpy_basics.py`**:
   - `ndarray` dimensional characteristics, shape inspection, memory allocation.
   - Array generation routines: `zeros()`, `ones()`, `eye()`, `arange()`, `linspace()`.
   - Element slicing, array copy vs view mechanisms.
   - Broadcasting, boolean masking, and matrix dot product multiplication.

2. **`matplotlib_visualizations.py`**:
   - Comprehensive plotting functions:
     - Formatted Line Graphs with custom markers and grid lines.
     - Categorical Bar Charts and Horizontal Bars.
     - Segmented Pie Charts with percentage labels.
     - Histograms and Gaussian normal distribution analysis.
     - 2D Scatter Plots.
     - Multi-panel $2 \times 2$ Subplots.

---

## 🚀 How to Run

```powershell
python numpy_basics.py
python matplotlib_visualizations.py
```
