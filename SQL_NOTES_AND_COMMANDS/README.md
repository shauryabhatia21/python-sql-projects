# SQL Reference Guide & Commands

A structured reference guide covering core SQL categories (DDL, DML, TCL), data types, and fundamental queries with syntax examples.

## Topics Covered
1. **Types of Commands**:
   - **DDL (Data Definition Language)**: `CREATE`, `ALTER`, `DROP`, `DESC`, `SHOW`
   - **DML (Data Manipulation Language)**: `INSERT`, `UPDATE`, `DELETE`, `SELECT`
   - **TCL (Transaction Control Language)**: `COMMIT`, `ROLLBACK`
2. **Data Types**: `INT`, `VARCHAR`, `CHAR`, `DECIMAL`, `DATE`, `BOOLEAN`, `BLOB`
3. **Hands-on Syntax Examples**: Working database creation and student table queries.

## Usage
Open and execute `sql_basic_guide.sql` in MySQL Workbench or MySQL CLI:
```sql
source sql_basic_guide.sql;
```
