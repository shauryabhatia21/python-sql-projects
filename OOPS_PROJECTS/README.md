# 🏛️ Object-Oriented Programming (OOP) in Python

Real-world applications implementing encapsulation, inheritance, method overriding, and class hierarchies.

---

## 📂 Projects Index

1. **`bank_application_oops.py`**:
   - `Bankacc` class with auto-generated unique SBI account numbers.
   - Deposit, withdrawal with balance checks, enquiry, and account listings.

2. **`calculator_inheritance.py`**:
   - `Calculator` base class for basic arithmetic (`+`, `-`, `*`, `/`).
   - `LogicalCalculator` derived class extending functionality with `square()` and `square_root()`.

3. **`student_class_inheritance.py`**:
   - 3-tier multi-level inheritance:
     - `PDetail` (Enrollment, Name, Course, Fees)
     - `Marks` (Term 1 & Term 2 exam marks)
     - `Result` (Total marks, percentage calculation, pass/fail evaluation)

---

## 🚀 How to Run

```powershell
python bank_application_oops.py
python calculator_inheritance.py
python student_class_inheritance.py
```
