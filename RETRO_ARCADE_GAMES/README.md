# Python 2D Retro Arcade Games

A collection of 5 classic 2D retro arcade games built in Python using **Pygame** with custom graphics, audio effects, score tracking, and collision physics.

---

## 🎮 Included Games

### 1. Operation Vanguard: Tactical Commando (`commando_game.py`)
- **Genre**: 2D Tactical Top-Down Commando Shooter.
- **Features**: Player movement, weapon firing, health systems, enemy waves, sound effects, and level progression.
- **Launch**:
  ```bash
  python commando_game.py
  ```

### 2. Space Invaders / Space Game (`mygame1.py`)
- **Genre**: Classic Space Shooter.
- **Features**: Spaceship control, enemy alien UFO waves, laser firing, explosion physics, background music, and score counter.
- **Launch**:
  ```bash
  python mygame1.py
  ```

### 3. Galaxy Striker (`shooting_game.py`)
- **Genre**: Space Combat Arcade.
- **Features**: Dynamic starfields, enemy fleet combat, power-ups, and sound FX.
- **Launch**:
  ```bash
  python shooting_game.py
  ```

### 4. Turbo Rush (`racing_game.py`)
- **Genre**: Retro High-Speed Car Racing.
- **Features**: Obstacle dodging, speed progression, score leaderboard, and road mechanics.
- **Launch**:
  ```bash
  python racing_game.py
  ```

### 5. Tic-Tac-Toe (`tick tak tow game.py`)
- **Genre**: 2-Player Strategy Board Game.
- **Features**: Turn-based grid logic, win detection, draw detection, and instant restart.
- **Launch**:
  ```bash
  python "tick tak tow game.py"
  ```

---

## 🛠️ Prerequisites & Setup

1. **Install Python 3.8+**
2. **Install Pygame**:
   ```bash
   pip install pygame
   ```

3. **Run any game**:
   ```bash
   python mygame1.py
   ```

## 🎨 Assets
All audio files (`.wav`) and visual sprite textures (`.png`) are included directly in the root directory for out-of-the-box playability.
