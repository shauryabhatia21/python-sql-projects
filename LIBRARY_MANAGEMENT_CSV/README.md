# Library Management System (Python & Pandas CSV)

A lightweight file-based Library Management System built in Python using `pandas` and CSV files.

## Features
- **Book Management**: Add, remove, modify, search, and view book inventory.
- **Member Management**: Register, update, and manage member profiles.
- **Issue & Return**: Issue books, track due dates (10 days borrowing window), update book availability status, and return books.
- **Persistent Storage**: All records stored locally in `books.csv`, `members.csv`, and `issue.csv`.

## Dependencies
- Python 3.x
- pandas (`pip install pandas`)

## How to Run
```bash
python main_module.py
```
