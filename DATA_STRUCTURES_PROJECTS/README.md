# 📊 Data Structures in Python (Dictionaries & Lists)

Fast, in-memory CRUD management applications utilizing Python dictionaries (hash maps) and lists with dynamic key generation.

---

## 📂 Projects Index

1. **`bank_dict_system.py`**:
   - Kotak Mahindra Bank management.
   - Key features: Auto-generated 8-digit accounts, balance updates, withdrawals with overdraft checks, account closure, and peer-to-peer balance transfer.

2. **`student_dict_system.py`**:
   - Academic record system indexed by enrollment number.
   - Operations: Add, search, rename, edit course/fees, and purge records.

3. **`contact_book_dict.py`**:
   - Address and telephone book with custom masked ID generator (`XI...XO...`).
   - Dynamic record updates for phones and emails.

4. **`generators.py`**:
   - Central utility providing randomized unique account numbers and alpha-numeric masked contact IDs.

---

## 🚀 How to Run

```powershell
python bank_dict_system.py
python student_dict_system.py
python contact_book_dict.py
```
